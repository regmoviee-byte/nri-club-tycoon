# Проверенный играбельный срез

Ветка `recovery-playable-build` подготовлена 19 октября 2026 года для согласованного переноса в `main`. Игровой код и оформление сохранены без изменений из checkpoint `a54628ae5af38e8578e952a90986d90f9db9a997`.

Исходный архив: `nri-club-tycoon-source-a54628a.zip`, 930267 байт, SHA256 `7d24d1c1864fcecebadce20731b9e4bdbc29369d2a762d994f5edebf60923a46`. Проверены хеш архива и все 79 файлов исходного манифеста. Публичный срез содержит 36 файлов из разрешённого списка релиза; дополнительные сведения о восстановлении находятся в этом файле и `RECOVERY_MANIFEST.json`.

## Что работает

Графические персонажи, физическое перетаскивание на стулья, разговоры, очередь из 30 присутствующих при 20 местах, пять комнат, отдельный запуск полных столов, переход к ближайшему окончанию, индивидуальные отзывы и сохранение текущего клуба в браузере.

Это играбельный прототип. Экономика, строительство и покупки улучшений здесь не реализованы. Формула рейтинга v2 остаётся черновой калибровкой; её известные ограничения описаны в исходном HANDOFF. Не следует объявлять этот срез завершённым тайкуном.

## Перенос

`index.html` и `.nojekyll` уже лежат в корне ветки. HTML, CSS, JavaScript и SVG обслуживаются напрямую: сборщик, установка зависимостей и серверное приложение не нужны. Все runtime-файлы совпадают с исходным checkpoint по SHA256; точный список находится в `RECOVERY_MANIFEST.json`.

Статический срез проверен по проектному пути `/nri-club-tycoon/`. После согласованного переноса коммита в `main` существующая настройка GitHub Pages `Deploy from a branch → main → /(root)` подходит без переключений. До переноса эта ветка не является опубликованной Pages-версией.

`main`, настройки Pages и файлы основной облачной задачи при подготовке этой ветки не изменялись. Устаревшие заметки в исходных документах относятся к прежним локальным этапам; актуальный статус восстановления приведён здесь.
