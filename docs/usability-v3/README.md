# Исправления удобства — 21 октября 2026

Версия `20261021-usability-v3`. Исправлены перечисленные воспроизведения из аудита. Проверка опубликованной версии отмечается отдельно в квитанции выпуска.

Комнаты рисуются пустыми: никакой автоматической мебели или стен. Площадь покупается по общей смете с отменой. Мебель ставится повторными кликами. Добавлены контекстные меню, рабочие клавиши удаления и поворота, настройки управления и восстановление клубов из архива.

Проверено: 154 проверки модели; 21 сценарий интерфейса; новый клуб с обычным бюджетом, ручной постройкой и завершённой партией; сохранение после перезагрузки. Отдельно проверен приход посетителей к семи местам и измерен контраст подписей.

Конструктор проверен на 1440×900, 390×844, 320×568 и 844×390. Дополнительные проверки строительства — 1280×720. Варианты фигурок просмотрены на снимках реального конструктора.
